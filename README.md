# Resumo de atividade

## Nessa atividade foi dado exercícios para serem refeitos e corrigidos

## Esercícios feitos:
- Exercício 1: Cadastro de Livro
- Exercício 2: Cadastro de Aluno
- Exercício 3: Empresa
- Exercício 4: Pedido de Venda
- Exercício 5: Cadastro de Produtos
- Exercício 6: Sistema Escolar (Desafio)

## Exemplo:

## ex1:
```xml
<?xml version="1.0" encoding="UTF-8"?>

<livro>
<titulo>Banco de Dados
<autor>Maria Oliveira</autor>
<ano>2025</ano>
</livro>

## Corrigido:

<?xml version="1.0" encoding="UTF-8"?>

<livro>
<titulo>Banco de Dados</título>
<autor>Maria Oliveira</autor>
<ano>2025</ano>
</livro>

## o erro do código foi que a linha "<titulo>Banco de Dados" estava faltando fechar a TAG "título" e da forma certa ficaria assim: "<titulo>Banco de Dados</título>"
```
